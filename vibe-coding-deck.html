STEP 02 · Node.js

웹앱을 돌리려면 Node.js가 필요합니다.

다운로드 · nodejs.org  →  LTS 버전 권장

설치 후 — 터미널에서 확인

node -v v20.x.x # 버전이 나오면 정상 npm -v 10.x.x # 버전이 나오면 정상

버전 번호가 한 줄로 출력되면 설치 성공입니다. Node.js와 npm은 함께 설치됩니다.

오류가 뜬다면?

  • 먼저 · VS Code를 완전히 종료 후 재시작 → 다시 시도
  • 그래도 안 되면 · PATH 설정 문제일 가능성 → AI에게 물어보기
  • 설치 시 주의 · "Add to PATH" 체크박스를 빼먹지 말 것
실습 · 설치 후 node -v 와 npm -v 결과를 옆 사람과 맞춰보기.

STEP 03 · Git

Git을 깔고, 내 이름·이메일을
딱 한 번 등록합니다.

다운로드 · git-scm.com  ·  등록은 평생 1번이면 됩니다.

이름·이메일 등록 (한 번만)

# 터미널에서 — 한 줄씩 복사·붙여넣기 git config --global user.name "홍길동" git config --global user.email "my@email.com" # 확인 git config --global user.name 홍길동
안 하면? 나중에 저장(commit) 자체가 안 됩니다.
한 번만 설정하면 이후엔 자동 적용.

왜 이름·이메일이 필요한가?

Git은 모든 저장 기록에 "누가 저장했는가"를 함께 기록합니다. 여러 사람이 같은 프로젝트를 작업할 때 누가 어떤 변경을 했는지 추적하기 위해서입니다.

혼자 쓰더라도 Git의 기록 구조 자체가
이 정보를 요구하므로 등록은 필수입니다.

Claude Code는 작업할 때마다 이 파일을 자동으로 읽고 따릅니다. 즉, 한 번 잘 써두면 모든 대화에 같은 규칙이 적용됩니다.

01   Explorer에서 프로젝트 루트 우클릭
02   New File
03   파일명: CLAUDE.md

performance-system/ ├─ CLAUDE.md # ← 반드시 여기 (루트) ├─ index.html ├─ css/ ├─ js/ └─ sql/

서브폴더에 두면 안 됩니다.
루트에 있어야 Claude Code가 자동으로 읽습니다.

실제 예시

규칙은 구체적일수록 AI가 잘 따릅니다.

# 프로젝트 규칙 ## 개발 규칙 - HTML/CSS/JS 파일 반드시 분리 - 함수 추가 시 한국어 주석 작성 - SQL 문자열 직접 결합 금지 ## 데이터 규칙 - 지표 코드명은 snake_case 사용 (예: employment_rate) - 연도는 학년도 기준 (3월~익년 2월) - NULL 허용 여부는 컬럼마다 명시
# (이어서) ## 보안 규칙 - DB 접속 정보는 .env에서만 관리 (코드에 직접 쓰지 말 것) - SQL 파라미터는 바인딩 변수 사용 # .env 읽기 금지 / 개인정보 필터링 → Hook에서 처리 ## 명령 규칙 - 위험 명령(DROP·DELETE) 실행 전 사용자 확인 필수
규칙이 명시적일수록 AI 출력이 예측 가능해집니다.

안전장치 · Hook

Hook은 CLAUDE.md와 달리 AI가 우회할 수 없습니다.

CLAUDE.md는 AI가 읽는 지침 — 무시될 수 있습니다. Hook은 도구 실행 전후에 실제 코드가 개입하므로 반드시 실행됩니다.

경고

DROP TABLE 같은 명령은 실행 전에 한 번 더 확인합니다.

개인정보 출력 검사

응답에 학번·주민번호 패턴이 보이면 출력 전에 걸러냅니다.

.env 읽기 금지 · 개인정보 필터링처럼 반드시 막아야 하는 항목은 CLAUDE.md 대신 Hook으로 처리합니다.

보안 ①

.env는 절대로 다음 셋과 만나면 안 됩니다.

DB 비밀번호 · API Key 등 민감한 정보가 들어가는 파일. 노출되면 비밀번호를 길에 흘리는 것과 같습니다.

.env 안에는 이런 게 들어갑니다

DB_HOST=서버주소 DB_PORT=1433 DB_NAME=데이터베이스명 DB_PASSWORD=**** API_KEY=****

원칙

금지 Git에 올리기GitHub에 올라가면 전 세계에 공개
금지 타인과 공유비밀번호를 직접 주는 것과 동일
금지 AI에게 내용 읽히기프롬프트에 포함될 수 있음
필수 .gitignore 등록Git이 이 파일을 무시하도록
필수 Hook 설정AI가 .env 접근 시도 시 자동 차단 — CLAUDE.md보다 강함

검증

"동작한다"와 "맞게 동작한다"는 다릅니다.

AI는 그럴듯하게 틀린 코드를 만들 수 있습니다. 특히 DB 쿼리·계산 로직·권한 처리는 반드시 확인합니다.

검증 항목확인 방법
달성률 계산대표 지표 몇 개를 손으로 계산해서 결과와 대조
DB 쿼리실행 결과가 예상 데이터와 일치하는지
권한 처리일반 사용자가 관리자 기능에 접근 가능한지
보안개인정보가 의도치 않게 노출되지 않는지
AI 출력은 초안입니다. 달성률·쿼리·권한 처리는 직접 확인합니다.
